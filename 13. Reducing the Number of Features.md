13. Reducing the Number of Features

Imagine a dataset with 100 features per example.

Some features may contain very similar information.

For example:

$$ x_1 = \text{height in cm} $$ $$ x_2 = \text{height in inches} $$

These two features carry almost the same information.

So instead of keeping 100 dimensions, we may be able to represent the important information using only, say, 20 dimensions.

This is called dimensionality reduction.

Simple picture
100 features
     ↓
 Remove redundant information
     ↓
20 new features

The goal is:

Use fewer dimensions while preserving as much useful information as possible.

One important use is visualization.

For example:

$$ 100D \rightarrow 2D $$

Then we can plot the data on a graph.

PCA is one of the standard methods for doing this. The course explicitly lists dimensionality reduction among the skills covered.
