## 12. TensorFlow Implementation of Content-Based Filtering

This is the next topic in Week 2. It is a short implementation lesson that puts the **deep-learning content-based filtering idea** into TensorFlow/Keras. ([Coursera][1])

The easiest way to understand it is as a **two-tower model**.

### 1. Two neural networks

We create one neural network for the **user** and another for the **item/movie**:

```text
User features
     ↓
 User NN
     ↓
   vᵤ
```

```text
Movie features
     ↓
 Movie NN
     ↓
   vₘ
```

The networks transform their original features into compact vectors \(v_u\) and \(v_m\). The course's TensorFlow implementation uses multiple `Dense` layers for these two networks. ([Scribd][2])

For example, conceptually:

```python
user_NN = Sequential([
    Dense(256, activation="relu"),
    Dense(128, activation="relu"),
    Dense(32)
])

item_NN = Sequential([
    Dense(128, activation="relu"),
    Dense(64, activation="relu"),
    Dense(32)
])
```

The exact layer sizes are implementation details; the important concept is that **both networks ultimately produce vectors of the same size**.

---

### 2. Normalize the vectors

The course then normalizes \(v_u\) and \(v_m\) so that they have unit length. ([Architech][3])

Conceptually:

$$
v_u \leftarrow \frac{v_u}{\|v_u\|}
$$

$$
v_m \leftarrow \frac{v_m}{\|v_m\|}
$$

Why?

Because we mainly want the model to compare the **direction/similarity** of the vectors rather than letting their magnitude dominate.

---

### 3. Compare user and item

Now calculate:

$$
\boxed{\text{score}=v_u\cdot v_m}
$$

So the complete flow is:

```text
User features ──→ User NN ──→ vᵤ ──┐
                                     ├→ dot product → score
Movie features ─→ Item NN ──→ vₘ ──┘
```

A higher score means the learned user representation and item representation are a better match.

---

### 4. How does it learn?

During training, we have examples of users interacting with or rating items.

The model produces a score:

$$
v_u\cdot v_m
$$

Then compares that score with the target \(y\).

The neural networks are trained through the usual process you already know:

$$
\boxed{\text{Prediction → Loss → Backpropagation → Parameter update}}
$$

So your Course 2 neural-network knowledge directly applies here.

---

### 🧠 The whole concept in one picture

```text
             CONTENT-BASED RECOMMENDER

      User features                 Item features
           ↓                            ↓
       User NN                       Item NN
           ↓                            ↓
          vᵤ                           vₘ
           ↓                            ↓
           └──────── Dot Product ──────┘
                         ↓
                  Match / Score
                         ↓
                   Recommendation
```

### The key thing to remember

> **Two neural networks learn embeddings for users and items. Normalize them, take their dot product, and use that score to determine how well the item matches the user.**
