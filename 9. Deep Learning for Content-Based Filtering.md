## 9. Deep Learning for Content-Based Filtering 🧠🎬

This is the next lesson in Week 2. The official course specifically teaches a **content-based recommender using deep learning**. ([Coursera][1])

The big idea is:

> Instead of directly comparing raw user/item features, use neural networks to convert them into useful **feature vectors (embeddings)** and then compare those vectors.

### 1. We have two inputs

For a user:

$$
x_u
$$

For a movie/item:

$$
x_m
$$

For example:

```text
User features:
age, country, favorite genres, etc.

Movie features:
genre, actors, year, etc.
```

### 2. Two neural networks

We create two networks:

```text
User features x_u
       ↓
   User Neural Network
       ↓
    v_u  ← user vector


Movie features x_m
       ↓
  Movie Neural Network
       ↓
    v_m  ← movie vector
```

The actual course implementation uses separate neural networks to produce these user and item vectors. ([GitHub][2])

### 3. Compare the vectors

Once we have:

$$
v_u
$$

and

$$
v_m
$$

we calculate their **dot product**:

$$
\boxed{\hat y = v_u\cdot v_m}
$$

The intuition:

* large dot product → user and item are a good match
* small dot product → weaker match

So:

```text
User → v_u ─────┐
                ├→ dot product → predicted preference
Movie → v_m ────┘
```

### 4. How does the network learn?

We have training examples where users interacted with or rated items.

The network tries to make:

$$
v_u\cdot v_m
$$

close to the actual preference \(y\).

A squared-error objective can be used:

$$
(v_u\cdot v_m-y)^2
$$

and the neural networks are trained using **backpropagation + gradient descent/optimization**. ([mai4car.eu][3])

### 🔥 Why is this powerful?

Remember Course 2?

You learned:

> **Neural network → learns useful representations from raw features.**

That's exactly what's happening here.

Instead of manually saying:

```text
User likes action = 8/10
Movie action level = 9/10
```

the networks learn vectors that capture useful characteristics automatically.

### 🧠 One very important distinction

**Collaborative filtering:**

$$
\text{ratings/interactions} \rightarrow \text{learn user/item vectors}
$$

**Deep content-based filtering:**

$$
\text{user features + item features}
\rightarrow
\text{neural networks}
\rightarrow
v_u,\ v_m
\rightarrow
\text{match}
$$

So this lesson is basically **bringing the neural-network knowledge from Course 2 into recommender systems**.
