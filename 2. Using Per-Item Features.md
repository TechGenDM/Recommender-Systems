## 2. Using Per-Item Features 🎬

This is the second lesson in Week 2. The course now adds **features for each item** to the recommendation problem. ([Coursera][1])

Let's use movies.

Suppose we have:

| Movie              | Romance \(x_1\) | Action \(x_2\) |
| ------------------ | --------------: | -------------: |
| Love at Last       |             0.9 |              0 |
| Romance Forever    |             1.0 |           0.01 |
| Cute Puppies       |            0.99 |              0 |
| Nonstop Car Chases |             0.1 |            1.0 |
| Swords vs Karate   |               0 |            0.9 |

So every movie now has a **feature vector**:

$$
x^{(i)}=
\begin{bmatrix}
\text{romance}\\
\text{action}
\end{bmatrix}
$$

For example:

$$
x^{(1)}=
\begin{bmatrix}
0.9\\
0
\end{bmatrix}
$$

means **Love at Last** is strongly romance-oriented and has almost no action.

---

### How do we use these features?

Suppose we're trying to predict **Alice's rating**.

We can learn parameters specifically for Alice:

$$
w^{(Alice)},\ b^{(Alice)}
$$

Then predict:

$$
\boxed{\hat y^{(i,Alice)}
= w^{(Alice)}\cdot x^{(i)}+b^{(Alice)}}
$$

This should look familiar.

It is basically **linear regression**:

$$
\hat y = wx+b
$$

except now we're using movie features to predict a user's rating. ([Scribd][2])

### Example

Suppose Alice's preferences are approximately:

$$
w^{(Alice)}=
\begin{bmatrix}
5\\
0
\end{bmatrix},
\qquad b^{(Alice)}=0
$$

For a movie with:

$$
x=
\begin{bmatrix}
0.99\\
0
\end{bmatrix}
$$

the predicted rating is:

$$
5(0.99)+0(0)=4.95
$$

So the system predicts that Alice will give it approximately:

$$
\boxed{4.95/5}
$$

### 🧠 What is happening?

The **movie provides the features**.

The **user provides the preferences/weights**.

```text
Movie features              User preferences
     ↓                            ↓
  Romance = 0.9              Likes romance a lot
  Action  = 0                 Doesn't care much about action
              \              /
               \            /
                ↓
           Predicted rating
```

This is an important transition:

> Instead of simply looking at movie ratings, we are now using **what the movie is like** to predict how much a particular user will like it.

And this sets up the next lesson, **Collaborative Filtering Algorithm**, where we'll learn how the system can actually **learn these user preferences and item features from the ratings themselves**. ([Coursera][1])
