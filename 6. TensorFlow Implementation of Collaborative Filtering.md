## 6. TensorFlow Implementation of Collaborative Filtering

Now we take the **collaborative filtering model we just learned** and implement it using **TensorFlow**. The official course places this lesson immediately after mean normalization. ([Coursera][1])

The important thing is: **TensorFlow does not change the algorithm.** It simply helps us calculate the cost, gradients, and parameter updates efficiently.

### 1. What are we learning?

Our model predicts a user's rating for an item:

$$
\hat y^{(i,j)}
=
w^{(j)}\cdot x^{(i)}+b^{(j)}
$$

where:

* \(x^{(i)}\) = features of movie \(i\)
* \(w^{(j)}\) = preferences of user \(j\)
* \(b^{(j)}\) = bias of user \(j\)

The model has to **learn all of these parameters**.

---

### 2. What does TensorFlow do?

We define the prediction:

```text
User preferences + Movie features
              ↓
          Prediction
              ↓
       Compare with actual rating
              ↓
             Cost
              ↓
       Calculate gradients
              ↓
       Update parameters
```

This is the same training loop you've already seen with neural networks.

### 3. The cost

For each known rating, we calculate the prediction error:

$$
\hat y^{(i,j)}-y^{(i,j)}
$$

and square it:

$$
(\hat y^{(i,j)}-y^{(i,j)})^2
$$

Then we add these errors together, usually with regularization.

Conceptually:

$$
J =
\frac12
\sum_{(i,j)\in R}
(\hat y^{(i,j)}-y^{(i,j)})^2
+
\text{regularization}
$$

where \(R\) represents the ratings that we actually know.

---

### 4. TensorFlow's role

TensorFlow can automatically calculate derivatives of this cost:

$$
\frac{\partial J}{\partial w},
\quad
\frac{\partial J}{\partial x},
\quad
\frac{\partial J}{\partial b}
$$

Then an optimizer such as **Adam** updates them.

So:

```text
Initialize w, x, b
       ↓
Predict ratings
       ↓
Calculate cost J
       ↓
TensorFlow calculates gradients
       ↓
Optimizer updates w, x, b
       ↓
Repeat
```

Eventually, the model learns user preferences and item features that make its predicted ratings close to the observed ratings.

### 🧠 The important connection

You've already learned this pattern in neural networks:

$$
\boxed{\text{Forward} \rightarrow \text{Cost} \rightarrow \text{Gradient} \rightarrow \text{Update}}
$$

Collaborative filtering uses the **same optimization idea**, but the parameters being learned are different.

> **TensorFlow is the tool; collaborative filtering is the algorithm.**
