## 4. Binary Labels: Favourites, Likes & Clicks 👍

This lesson changes something important in recommender systems: **the user's feedback doesn't always come as a 1–5 star rating**. The official course covers binary feedback such as favourites, likes, and clicks here. ([Coursera][1])

### What are binary labels?

Instead of:

$$
y = 1,2,3,4,5
$$

we can represent user behaviour as:

$$
y \in \{0,1\}
$$

For example:

| User action      | Label |
| ---------------- | ----: |
| ❤️ Favourited    |     1 |
| 👍 Liked         |     1 |
| 🖱️ Clicked      |     1 |
| Didn't favourite |     0 |
| Didn't like      |     0 |
| Didn't click     |     0 |

So:

$$
1 = \text{positive interaction}
$$

$$
0 = \text{negative/no observed interaction}
$$

### Example

Suppose Alice sees 4 movies:

| Movie   | Alice's interaction |
| ------- | ------------------- |
| Movie A | Liked 👍            |
| Movie B | No interaction      |
| Movie C | Clicked 🖱️         |
| Movie D | Favourited ❤️       |

We could represent this as:

$$
y^{(Alice)}=[1,0,1,1]
$$

The recommender can then learn which items Alice is likely to interact with.

### Why is this useful?

Real recommendation platforms often have **implicit feedback** rather than explicit ratings.

For example:

> YouTube may not ask “How many stars would you give this video?”
> It can observe whether you **clicked, watched, liked, or skipped**.

So the system can learn from your behaviour.

### One important detail

A `0` doesn't necessarily mean:

> **“The user disliked it.”**

It can simply mean:

> **“We did not observe a positive interaction.”**

That's an important distinction.

For example:

```text
Movie A → user clicked       → 1
Movie B → user never clicked → 0
```

We don't actually know whether the user disliked Movie B. Maybe they simply never saw it.

### 🧠 Core idea

> **Binary feedback converts user behaviour into 0/1 signals that a recommender can learn from.**
