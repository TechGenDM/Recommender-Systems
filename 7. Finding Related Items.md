## 7. Finding Related Items 🔗

This is the next lesson in Week 2. The idea is surprisingly simple: **once collaborative filtering has learned a feature vector for each item, we can use those vectors to find similar items.** ([Coursera][1])

### Example

Suppose the model has learned these hidden features for movies:

| Movie   | Romance | Action |
| ------- | ------: | -----: |
| Movie A |     0.9 |    0.1 |
| Movie B |     0.8 |    0.2 |
| Movie C |     0.1 |    0.9 |

Movie A:

$$
x^{(A)}=[0.9,0.1]
$$

Movie B:

$$
x^{(B)}=[0.8,0.2]
$$

These two vectors are **close to each other**, so the movies are likely to be related.

Movie C:

$$
x^{(C)}=[0.1,0.9]
$$

is quite different.

### How do we measure similarity?

A simple idea is to calculate the **distance** between two item vectors.

For example:

$$
\|x^{(A)}-x^{(B)}\|^2
$$

If the distance is:

* **small** → items are similar
* **large** → items are different

So for a movie the user likes, we can search for other movies whose feature vectors are close to it.

```text
User likes Movie A
        ↓
Get Movie A's feature vector
        ↓
Compare with other movies
        ↓
Find closest vectors
        ↓
Recommend those movies
```

### Why this is powerful

Remember: we didn't necessarily tell the system:

> “Feature 1 = romance”
> “Feature 2 = action”

Collaborative filtering **learned useful item features from user behavior**.

Then we can use those learned features to discover related items.

### 🧠 Remember this

> **Collaborative filtering learns item vectors → similar vectors represent related items → related items can be recommended together.**
