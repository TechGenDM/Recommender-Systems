## 8. Collaborative Filtering vs. Content-Based Filtering

This is an important distinction in recommender systems. The official course introduces both approaches here before moving into **deep learning for content-based filtering**. ([Coursera][1])

### 1. Collaborative Filtering

Collaborative filtering looks at **user behavior**.

> “People who behaved similarly in the past may have similar preferences.”

Example:

```text
Alice → likes A, B, C
Bob   → likes A, B, C

Bob also likes D
       ↓
Recommend D to Alice
```

It can learn useful item features from the ratings/interactions themselves.

**Input:** user-item interactions/ratings.

---

### 2. Content-Based Filtering

Content-based filtering looks at **what the items are actually like**.

Suppose movies have features:

| Movie | Action | Comedy | Romance |
| ----- | -----: | -----: | ------: |
| A     |    0.9 |    0.1 |       0 |
| B     |    0.8 |    0.2 |     0.1 |
| C     |      0 |    0.1 |     0.9 |

If you liked Movie A, the system looks for movies with **similar content/features**.

```text
You liked Movie A
       ↓
Understand Movie A's features
       ↓
Find items with similar features
       ↓
Recommend them
```

---

### The core difference

|                  | Collaborative Filtering      | Content-Based                          |
| ---------------- | ---------------------------- | -------------------------------------- |
| Main information | User behavior                | Item characteristics                   |
| Learns from      | Many users                   | Item features + user preferences       |
| “Why recommend?” | Similar users/preferences    | Similar item content                   |
| Example          | “People like you liked this” | “You liked action movies, so try this” |

### A very important intuition

Imagine you are recommending movies to me.

**Collaborative filtering:**

> “Devasish and other users have similar movie preferences, and those users liked Movie X.”

**Content-based filtering:**

> “Devasish likes movies with these characteristics, and Movie X has similar characteristics.”

So:

$$
\boxed{\text{Collaborative} = \text{user behavior}}
$$

$$
\boxed{\text{Content-based} = \text{item characteristics}}
$$

And modern systems can also **combine both approaches**.

### 🧠 Remember this

> **Collaborative filtering asks: “Who behaves like you?”**
> **Content-based filtering asks: “What is similar to what you already like?”**
