# 14. PCA Algorithm

**PCA = Principal Component Analysis**

This is the actual algorithm that performs the dimensionality reduction.

### Start with a 2D dataset

Imagine points arranged roughly along a diagonal:

```text
x₂
↑
|             •
|           •
|         •
|       •
|     •
|   •
+----------------→ x₁
```

Although we have **two features**, most of the variation is happening along **one direction**.

PCA finds that important direction.

That direction is called a **principal component**.

```text
x₂
↑
|             •
|           •
|         •
|       / 
|     /   ← principal component
|   •
+----------------→ x₁
```

Then each point can be **projected onto that line**.

Now instead of describing each point with:

$$
(x_1,x_2)
$$

we can approximately describe it with just:

$$
z_1
$$

So:

$$
\boxed{2D \rightarrow 1D}
$$

---

### What is PCA really trying to do?

PCA looks for a lower-dimensional direction/subspace that preserves the important variation in the data.

Another equivalent way to think about it is:

> **Find a projection that minimizes the reconstruction error.** ([Coursera][2])

So PCA is not simply "delete some columns."

It **creates new axes** that are combinations of the original features.

For example:

$$
z_1 = 0.8x_1 + 0.6x_2
$$

The new feature \(z_1\) is a **principal component**.

### PCA in higher dimensions

Suppose:

$$
100D \rightarrow 10D
$$

PCA finds the **10 most important principal directions** and projects the original data onto them.

Conceptually:

```text
Original data
100 dimensions
      ↓
      PCA
      ↓
10 principal components
```
